# Prosper

Prosper Marketplace runs one of the largest US peer-to-peer (marketplace) lending platforms, matching individual and institutional investors with consumer borrowers, and also offers a HELOC and a credit-card product.

For investors, Prosper publishes a RESTful **Investor API** (OAuth 2.0 over SSL, production + sandbox) to view account balances, search active loan listings, place orders to purchase Notes, and track owned Notes, loans, and payments.

- Developer portal: https://developers.prosper.com/
- Investor API reference: https://developers.prosper.com/docs/investor/
- Base URL: `https://api.prosper.com/v1` (Listings service at `/listingsvc/v2/`); sandbox `https://api.sandbox.prosper.com/v1`
